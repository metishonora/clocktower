2026-09-11. 서버: 리뷰 서버(검증 당시) (최신 dist HTTP 확인, 유지).

사용자 시나리오 JSON으로 새 마도서를 만든다. 먼저 PC에서 아래 1–4를 수행하고 모바일에서 같은 흐름을 반복한다. 기존 BMR의 공통 화면과 TB/SnV의 해당 직업 화면을 비교 기준으로 삼는다.

| 항목 | 조작 | 기대 결과 |
|---|---|---|
| 1 순서 | 15인 직업 선택·배치 확정 | 시나리오에 둔 하수인→악마 정보부터 시작. 다음은 시나리오 직업 순서 |
| 2 준비 정보 | 세탁부/사서/수사관의 마도서 대상 선택→진행 정보 설정→공개 | 사용자 목록에 준비/전달 별도 행 없음. 정답·등록 판단이 필요한 경우에만 원본 위치에 입력 |
| 3 직접 행동 | 독살범 대상 선택·초기화·취소·확정 | actor/대상 강조, 선택 결과, 다음 복귀가 원본과 같고 확정은 한 번 |
| 4 통지 | 세레노버스 대상·직업 선택→확정→공개→닫기 | 대상 통지와 공개가 원본과 같고 다음 진행으로 복귀 |
| 5 역할 공개 | 숫자/꿈꾸는 자/쌍둥이/첩자 공개 | 역할별 입력·진실·오류·공개·닫기가 원본과 같음. 공개 payload 밖 비밀 없음 |
| 6 자유 행동 | 변종 dock 열기·판단·취소·처형 | 정규 순서 위 새 탭 없음. 현재 입력 보존. 처형 문구는 승인한 첫 문장만 |
| 7 복원 | 행동·판단 후 새로고침/JSON export-import/Undo | 기록과 상태 일치, 과거 공개 불변, 복원 시 비공개 |
| 8 공통 UI | 직업 확정 후 편집 시도, 비활성 직업 상세, 새 게임 취소, 저장·기록·모바일 | 원본 동작, BMR 테마, 글씨/버튼 잘림·겹침 없음 |
