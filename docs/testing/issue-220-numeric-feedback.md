# 숫자 정보 입력 공통 경로 보완 — 2026-09-12

사용자 첨부 test0912-game-3.json은 철학자가 시계공을 획득한 뒤 기존 시계공이 취한 상황이다. 정상 등록 판정 분기에서 빠진 숫자 후보가 과거 공통 버튼 목록과 실제 정체 취급 UI로 내려갔다.

수정은 시계공 전용 예외가 아니다. Core가 제공하는 유한 숫자 후보와 범위/제외값을 `numericInputDraft` 한 곳에서 검증하고 입력 상태에 반영한다. 기존 요리사·공감 능력자의 중복 후보 검증도 같은 경로로 통합했다. 원본 TB/SnV의 화면 배치만 유지한다. Core가 제공하지 않은 결과나 등록 판단을 만들지 않는다. 일반 취급 제목/실제 값 표시도 합의 문구로 교체했다.
