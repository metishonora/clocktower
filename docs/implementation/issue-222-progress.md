# #222 구현 기록

## 변경

- 작성 화면에 첫날 밤/이후 밤의 독립 편집·기본값 복원·코어 오류 표시를 연결했다. 모바일은 탭, 넓은 화면은 두 구획이며 기존 위/아래 버튼과 이동 애니메이션을 사용한다.
- 현재 phase를 기준으로 낮/밤 화면을 선택하고 코어 `nightNumber`로 현재 밤을 표시한다. 둘째 밤 이후에도 기존 controller, 세션, 입력·공개·Undo 흐름을 재사용한다.
- TB/SnV 이후 밤 행동 adapter와 정보 공개를 연결했다. 시장 판단, 임프 승계, 피트 해그 변신/사망, 이발사 선택 악마/대상, 비고르모르티스 중독은 코어 후보를 표시한다.
- 연결 중 부족했던 코어 읽기 계약을 보완했다: 대상별 공격 부가 입력, 선택 가능한 인원 수, 현재 밤 번호. 기존 공격 해석 함수를 재사용하며 캐릭터 규칙은 script 모듈에 둔다.
- 임프/팡 구 승계, 피트 해그, 이발사의 정체 변화가 기존 코어 통지 큐로 연결되도록 보완했다. 저장된 마지막 사건의 통지는 복원 후 비공개로 제시한다.
- 저장 파일 버전은 시나리오 v2/게임 v5를 유지한다. 공식 게임 계약은 변경하지 않았다.

- 브라우저 248개 범위 통과: 전체 실행 244 통과 후, 두 구획의 같은 버튼을 구분하지 못한 기존 테스트 selector를 수정하고 작성 화면 11개를 재실행해 모두 통과했다. #222의 6개 흐름도 포함한다.

## 인수 상태

[리뷰 절차와 파일](../testing/issue-222-review.md)을 제공한다. 인앱 브라우저에서 편집 화면을 수동 확인했고, 세 폭의 다중 밤·복원·Undo를 Playwright로 검증한다. 실제 사용자 인수와 실기기 검증은 아직 미확인이다. 리뷰 서버는 계속 유지한다. 이슈 종료/병합은 하지 않았다.

## 인수 피드백 수정

- 낮 탕녀 승계의 실제 직업 변경과 플레이어 통지 시점을 분리했다. 코어가 다음 밤 전환 때 통지를 제공하고, UI는 저장 후 비공개 안내를 연다. 원인 사건과 전달 사건을 구분해 재가져오기·재시도·Undo를 지원한다.
- 주정뱅이 좌석은 보여준 마을주민 아이콘·이름을 사용한다. 실제 직업과 능력 규칙은 유지하며 상세에서 두 직업을 비교할 수 있다. 토큰 개수와 상세 표시 방식은 기존대로 유지한다.
- 수정 후 custom Rust 202개, custom TypeScript/WASM 325개, 웹 integration 801개 통과. 저장 실패 후 재시도, 새로고침, JSON 복원, Undo와 군인으로 보이는 주정뱅이의 사망 판정을 포함한다.
- 최종 표시 범위 조정 후 웹 빌드 성공, 주정뱅이 UI 테스트 1개 및 모바일/데스크톱 정체 표시·탕녀 알림 브라우저 테스트 4개 통과. 기존 다중 밤 브라우저 흐름 6개도 통과했다.


## 공격 결과·후속 행동 점검 후 수정

다섯 악마의 공격, 마녀, 교환 없는 뱀 조련사, 실제 피트 해그 변신과 이발사 교환에 행동별 결과 확인 계약을 연결했다. 확정 사건에서 결과를 읽어 기존 마도서 결과 패널에 표시하며, 다음 버튼 이후 정체 통지 또는 진행으로 이어진다. 까마귀지기 등 이후 밤 후속 행동은 진행 탭에서 사용자가 시작한다.

저장 실패/재시도, 결과 중 입력 차단, 복원, 사망 없음·시장 반사·승계와 Undo를 테스트했다. custom 334개, integration 801개, #222 브라우저 10개 통과 및 production 빌드 성공. 상세는 [결과 화면 점검과 수정 기록](../testing/issue-222-result-screen-audit.md)에 남긴다.

기존 첫날 밤 브라우저 회귀 62개 범위 통과: 최초 54개 통과 후, 마녀 결과 확인을 반영한 4개와 새 뱀 조련사 무교환 결과 4개를 실행해 8개 모두 통과했다. 웹 아키텍처 검사도 통과했다.


## 시장 판단 UI 원본 대응

2026-09-15. 시장 판단 드롭다운을 기존 TB의 두 선택지와 마도서 좌석 선택으로 교체했다. 원래 공격 대상과 대신 사망 대상을 분리하고, 후보는 코어 응답을 그대로 사용한다. 대상 초기화·판단으로 취소·공격 대상 변경·Undo 시 입력 정리를 검증했다. 저장과 코어 공격 명령 형식은 유지한다.

custom 335개, integration 801개, 시장 및 다중 밤 브라우저 8개 통과. 아키텍처 검사와 웹 빌드 성공.


## 완료 범위 합의 — 2026-09-15

사용자는 현재 구현과 인수 피드백 반영 상태를 승인하고 #222 finalize를 요청했다. 이번 완료 범위는 이후 밤 순서 편집·다중 밤 진행 UI 연결, 대표 흐름 검증, 발견한 화면 결함 수정과 인수 자료 제공이다. 개별 캐릭터별 사용자 인수 테스트는 다른 작업 완료 후 수행하기로 합의하여 연기했다. 전체 캐릭터의 수동 인수 또는 실기기 검증 완료를 주장하지 않으며, 연기한 검증은 이번 종료의 미해결 구현 결함과 구분한다.

새 Rust 테스트는 workspace/custom-domain 테스트에, TypeScript·UI 테스트는 custom 및 integration suite에, 브라우저 테스트는 Playwright 전체 탐색에 포함되며 PR의 Validate Clocktower CI에서 실행된다.
