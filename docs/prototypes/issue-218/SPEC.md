# #218 · 마도서 콘솔 프로토타입 스펙

2026-09-09 대화에서 합의한 다음 프로토타입의 제작 기준. 기존 시안은 예시이며 최종 디자인 승인이 아니다. 아래 기준으로 조작 가능한 시안을 먼저 제작하여 사용자의 디자인·상호작용 검토를 받는다.

## 시각 방향

- 동화 같은 밝은 종이, 둥근 손글씨, 귀여운 삽화에서 벗어나 뉴시나리오 선택 화면의 사악한 마도서 분위기를 이어간다.
- 검은 공간, 오래된 양피지, 거친 잉크, 절제된 금속 장식과 붉은 실을 공통 재료로 삼는다. 읽는 면에는 빛이 모이고 주변은 어둡게 표현한다.
- 제목·짧은 서술에는 필사 분위기를, 이름·배역·숫자·조작에는 선명한 글자를 사용한다. 완성된 책 배경에 업무용 UI를 덧씌우지 않고 종이·글자·조작을 함께 디자인한다.
- 이름, 배역, 상태, 조작 가능한 텍스트에 일관된 강조 규칙을 적용한다. 색상만으로 정보를 구별하지 않는다.
- 기존 #205 시나리오 편집 화면의 승인 사항은 유지한다.

## 화면 구조와 기존 컴포넌트 배치

이야기 본문이 기존 진행 및 이벤트 로그 화면을 대체한다. 별도의 배치 화면과 저장 화면을 제공한다.

| 기존 기능 | 프로토타입에서의 위치 |
| --- | --- |
| 좌석·플레이어·배역·생사·토큰 | 배치 종이 |
| 선택한 플레이어의 상세·메모·상태 수정 | 배치 종이와 연결된 상세 영역 |
| 현재 행동·대상 선택·정보 입력·전달 | 진행 본문의 현재 문단 |
| 진행 순서 | 본문 주변의 간결한 순서 표시 |
| 완료 행동·이벤트 로그 | 본문에 쌓이는 과거 기록 |
| 단계 전환·되돌리기 | 현재 문단 가까이의 일정한 위치 |
| 기기 저장·파일 저장·불러오기 | 별도 저장 화면 |

- 데스크톱: 좌측 배치, 우측 진행을 함께 볼 수 있는 구성을 우선 제작한다. 배치만 보는 화면도 제공한다.
- 모바일: 진행 본문 아래에 배치 종이 끄트머리와 ‘배치’ 표식을 노출한다. 누르면 별도의 종이를 꺼내고 다시 닫을 수 있다.
- 배치 종이를 닫거나 저장 화면에서 돌아와도 작성 중인 문단, 입력 값, 스크롤 위치가 유지된다.
- 단순 선택은 문장 안에서, 여러 대상·배역 등 복잡한 선택은 해당 문단 아래의 입력 영역에서 처리한다.

## 배치와 진행의 연결

- 현재 행동자와 선택 대상이 배치와 본문 양쪽에서 함께 강조된다.
- 본문의 이름으로 해당 인물을 찾고 상세를 확인할 수 있다.
- 대상 선택 중 배치의 플레이어를 눌러 선택할 수 있다.
- 모바일 배치 종이에서 선택할 때도 어떤 행동의 대상을 고르는지 확인할 수 있다.
- 인물 상세에서 예시 이름·배역·생사·토큰·메모를 수정해 기존 조작의 수용 방식을 검토한다. 새 규칙이나 도메인 동작은 구현하지 않는다.

## 기록과 실수 복구

- 현재 문단과 완료된 문단을 구별하되 과거 기록도 충분한 대비로 읽을 수 있게 한다.
- 이름은 굵기, 배역은 아이콘 및 글자, 상태는 표식으로 구분한다. 조작 가능한 이름에는 별도 표시를 둔다.
- 기록에는 행동 당시 이름·배역·선택·결과를 보존한다. 이후 현재 배치가 바뀌어도 과거 문장의 의미가 바뀌지 않는다.
- 낮·밤을 장 단위로 묶어 접기 및 장 이동, ‘현재 진행’ 복귀를 검토한다. 첫날 밤 이외의 기록은 탐색용 정적 예시다.
- 되돌리기 전에 영향을 받는 기록과 상태를 구체적으로 보여준다.

## 플레이어 정보 공개

- 공개 중에는 이야기꾼 본문, 데스크톱 배치, 모바일 배치 끄트머리, 메모 및 검토 도구를 숨긴다.
- 정보 공개 → 가리기 → 이야기꾼의 명시적인 전달 완료·복귀 동작을 거친다. 가리기만으로 비공개 배치가 바로 드러나지 않는다.
- 다시 펼치기와 이미 전달한 정보 확인을 검토한다.

## 저장 화면

- 기기 저장과 파일 저장·불러오기를 시각적으로 구분하고 ‘파일로 저장’, ‘불러오기’ 같은 명확한 행동명을 유지한다.
- 저장 시점, 저장/불러오기 결과, 기존 진행을 바꾸는 확인 상태를 예시로 검토한다.
- 실제 게임 저장·불러오기 및 저장 계약은 연결하지 않는다. 프로토타입의 저장 피드백은 시뮬레이션임을 검토 도구와 저장 화면 주변의 별도 검토 안내에 명시한다. 제품을 표현한 종이 안과 검토용 설명은 구분한다. 실제 연결은 #205에서 수행한다.

## 이번 프로토타입의 대표 검토 상태

1. 데스크톱 배치+진행과 독립 배치 화면.
2. 모바일 배치 종이 열기·대상 선택·복귀.
3. 플레이어 상세, 생사·토큰·메모 수정 및 현재 상태 강조.
4. 하수인 정보 공개 → 악마의 속임수 세 가지 선택 → 정보 공개 → 요리사 및 점쟁이의 예시 입력·대상 선택.
5. 완료 기록 누적, 장 탐색, 현재 진행 복귀 및 되돌리기.
6. 플레이어 공개, 가림 및 이야기꾼 복귀.
7. 별도 저장 화면과 저장·불러오기 확인/피드백 예시.
8. 많은 인원·토큰, 긴 이름, 여러 대상 선택, 좁은 모바일 및 데스크톱에서의 가독성·조작 가능성.

## 범위 및 완료 판단

- 격리된 프런트엔드 시안과 예시 데이터만 사용한다. 프로덕션 UI·규칙·데이터 모델·저장 계약을 변경하지 않는다.
- 첫날 밤 이후 런타임이나 새 캐릭터 능력을 추가하지 않는다. TB/SNV 전체 테마 적용은 별도 범위 합의가 필요하다.
- 데스크톱/모바일에서 조작 확인, 관련 웹 빌드, prototype_reviewer 사전 검토 후 사용자에게 제시한다.
- 본 스펙의 제작 승인은 시각 결과의 최종 승인을 뜻하지 않는다. 사용자 검토 이후 결정·미결 사항을 기록하여 #205로 넘긴다.
