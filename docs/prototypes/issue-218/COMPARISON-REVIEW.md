# #218 · 고정 화면 전환 A/B

사용자 요청: 줌 중 책이 흔들리는 문제를 피하면서 컨셉·분위기를 환기하는 두 방법을 모두 보기. 이전 줌 전환과 본문 프로토타입은 변경하지 않았다.

## 범위와 재현

http://100.91.205.43:10218/clocktower/issue-218-transition-compare.html

- A · 책장 넘김: 카메라와 본문은 고정하고, 접힌 가장자리와 명암이 오른쪽에서 왼쪽으로 넘어가며 다음 장면을 드러낸다. 전체 책의 3D 회전은 없다.
- B · 잉크 번짐: 불규칙한 가장자리의 잉크 얼룩들이 퍼져 본문을 덮은 뒤 낮 장면을 드러낸다.
- 같은 밤 종료/낮 시작 예시와 삽화, 기본 1.6초(느리게 3.2초)를 사용한다. 제품 조작은 기존 ‘확인하고 낮 시작’이다.
- A/B 선택, 재생, 초기화, 느리게, 전환 위치 슬라이더는 제품 밖 도구다. 슬라이더는 실제 효과의 임의 시점을 재현한다.
- 실제 게임/기록 저장/선택지는 연결하지 않는다. 낮 진입 때 밤 기록이 같은 본문에 계속 쌓이지 않고 새 장면으로 시작하는 예시다.
- reduced-motion에서는 바로 낮으로 이동한다. 해당 OS 설정을 변경한 실기 검증은 하지 않았다.

## 확인

- CUA 수동: 데스크톱 A/B 전체 재생과 낮 도착, 현재 낮 본문 포커스. 모바일 390px B 전체 재생 및 두 중간 장면, 320px A 시작·본문·가로 넘침 확인.
- 본문 레이어와 화면의 CSS transform이 none임을 확인했다. 장면 이동/확대가 없다.
- 브라우저 오류/경고 없음. `pnpm --dir web build` 통과. 자동화/회귀 테스트는 작성하거나 실행하지 않았다.
- prototype_reviewer: 제한된 범위, 검토 도구 분리, 격리성 통과. 데스크톱 도착 화면과 데스크톱/모바일 중간 캡처 검토. 전체 develop 외곽 UI와의 비교 및 정지 모바일 캡처의 별도 리뷰는 미검증이다. 모바일 시작 화면은 구현 담당자가 직접 확인했다.
- 최종 선택과 분위기에 대한 사용자 평가는 아직 없다.
