# #218 · 마도서 전체 테마 검토 시작점

#205에서 분리된 이야기형 콘솔 시안이다. 초기 시안의 “시안으로선 무난” 평가는 당시 검토 시작점에 대한 것이며, 이후 v2/v3는 디자인 재검토 대상이 되었다. #218 테마 검토 완료 후 #205 Production UI 연결을 재개한다.

## 현재 시안 · 카메라 고정 전환 A/B

**[두 전환 비교](http://100.91.205.43:10218/clocktower/issue-218-transition-compare.html)** · [범위와 확인 기록](COMPARISON-REVIEW.md)

A는 접힌 책장 가장자리가 왼쪽으로 넘어가며 낮 본문을 드러낸다. B는 잉크 얼룩이 화면을 덮었다가 낮 본문을 드러낸다. 두 방식 모두 본문·카메라의 이동 없이 같은 예시를 1.6초에 전환한다. 상단 A/B를 고른 뒤 ‘확인하고 낮 시작’ 또는 검토 도구의 ‘재생’을 누른다. 느리게 및 전환 위치로 중간 모습을 비교할 수 있다. **선택과 시각 평가는 사용자 검토 전이다.**

## 이전 시안 · 밤 → 낮 전환 한 번 (2026-09-10)

**[밤낮 전환 시안](http://100.91.205.43:10218/clocktower/issue-218-transition.html)** · [검토 범위와 확인 기록](TRANSITION-REVIEW.md)

## 이전 시안 · 진행 본문 한 장면

사용자가 이야기 누적형과 ‘마도서 줌아웃 → 책장 넘김 → 장면 줌인’ 전환 방향을 선택하고, 먼저 줌인된 진행 본문 한 장면만 제작하도록 승인했다.

**[진행 본문 시안](http://100.91.205.43:10218/clocktower/issue-218-scene.html)** · [최신 스펙](SPEC.md) · [범위·검증 기록](SCENE-REVIEW.md)

공개를 마친 하수인 예시에서 ‘다음으로’를 누르면 기존 문장이 기록으로 남고 악마 문장이 아래에 이어진다. 책장 전환·선택지·공개·배치·저장은 이번 시안에 포함하지 않는다. 2026-09-10 사용자에게 가독성 개선과 분위기·책 본문 같은 느낌에 긍정 평가를 받았다. [평가 기록](https://github.com/metishonora/clocktower/issues/218#issuecomment-5604088422). 삽화 재사용·직업별 삽화는 미정이다.

## v2 보존 기록 · 2026-09-09

[합의한 제작 스펙](SPEC.md) · [이슈 스펙 기록](https://github.com/metishonora/clocktower/issues/218#issuecomment-5601488681)

검토 주소: http://100.91.205.43:10218/clocktower/issue-218-story.html

동화 같은 손글씨 시안에서, 검은 공간·양피지·붉은 잉크·의식 문양을 사용하는 마도서 콘솔로 확장했다. 공유 카탈로그 및 기존 배역 이미지·종이 질감을 재사용하며 제품 화면과 규칙 엔진은 변경하지 않았다.

- 진행: 데스크톱 좌측 배치/우측 본문. 하수인 → 악마의 속임수 3개 → 요리사 숫자 → 점쟁이 대상 2명 및 예/아니오 → 완료 기록.
- 모바일: 밑쪽 ‘배치’ 종이를 꺼내 좌석을 선택한다. 현재 행동과 복귀 버튼은 고정되고 배치 안을 스크롤한다.
- 독립 배치: 이름·배역·생사·토큰·메모를 예시 상태에 반영한다. 진행 본문의 이름에서도 인물 상세를 연다.
- 기록: 완료 시 당시 이름·배역·결과를 보존한다. 목차/장 접기/현재 진행 복귀, 마지막 전달 기록 되돌리기를 제공한다. 이후 낮/밤은 별도의 정적 탐색 예시다.
- 공개: 이야기꾼 화면 전체를 렌더에서 제거하고 전달 정보만 표시한다. 정보 가리기 후 명시적으로 돌아온다. 이미 전달한 정보도 당시 내용으로 다시 열 수 있다.
- 저장: 기기/파일 저장, 불러오기 확인·취소·복원은 메모리 안에서 시뮬레이션한다. 실제 파일 생성이나 기기 저장소 쓰기는 없다. 종이 바깥 검토 안내에 한계를 명시한다.
- 검토 도구: 12명 초기 상태, 15명/긴 이름/다중 토큰, 대상 선택 바로 보기, 긴 기록 탐색.

### 검증

- CUA 수동: 네 단계 전달, 속임수 3개 제한, 대상 2명 제한, 공개/가림/복귀, 전달 완료 후 다음 문단 이동, 되돌리기 후 선택 보존.
- CUA 수동: 기기·파일 저장 시뮬레이션 및 불러오기 확인/취소/복원, 인물 이름·배역·생사·메모 변경, 현재 배치 변경 이후 과거 기록 보존, 목차/현재 진행 왕복.
- 데스크톱 1440×1000, 모바일 390×844 및 320×740 확인. 15명 상태의 세로 간격과 모바일 종이의 고정 조작을 조정했다. 320px에서 가로 넘침 없음 확인.
- 브라우저 콘솔 오류/경고 없음. `pnpm --dir web build` 및 TypeScript 검사 통과. 빌드는 프로덕션 회귀 컴파일 검사이며, 격리된 시안은 위 URL에서 별도로 수동 검토했다.
- 자동 테스트는 작성하거나 실행하지 않았다.
- `prototype_reviewer`: 현재 v2 캡처·코드 검토에서 겹침 등 발견된 시각 차단 사항 없음, 범위/검토 도구 분리/격리성 확인. 기존 develop 화면과의 픽셀 일치 비교는 수행하지 않았다. 시각 결과의 최종 승인은 사용자 검토 대기다.
