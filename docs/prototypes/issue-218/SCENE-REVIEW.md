# #218 · 진행 본문 한 장면

## 승인된 범위

이야기는 같은 밤/낮 안에서 누적된다. 최초 진입과 밤/낮 전환의 마도서 줌아웃·책장 넘김·줌인은 후속 컴포넌트다. 이번에는 줌인된 진행 본문 한 장면만 만든다. 이전 전체 콘솔 시안은 수정하지 않았다.

## 기존 콘솔 대응

- `TroubleBrewingProgress.tsx`의 하수인 정보 단계와 공개 후 ‘다음으로’ 동작을 참고했다. 단계 제목은 ‘첫날 밤’, 예시 행동자는 2번 영희·3번 민수, 악마는 1번 수빈이다.
- 시작 상태는 공개를 이미 마친 예시다. ‘다음으로’를 누르면 하수인 문장이 기록으로 남고 악마 문장이 추가된다. 다음 선택 UI는 만들지 않는다.
- 이름은 굵은 글자, 좌석은 작은 숫자, 하수인/악마는 붉은 색과 굵기로 구분한다. 의미 있는 문장 외 장식 문구를 제품에 추가하지 않았다.
- 안개와 빛은 느리게 움직이고 본문은 정지한다. 새 문장은 짧게 나타난다. reduced-motion에서는 움직임을 제거한다.
- 기존 v3의 목판화 자산을 재사용하되 책·종이 외형은 사용하지 않는다. 삽화는 기존 자산으로 새 생성/편집은 하지 않았다.
- 검토 안내와 ‘처음으로’는 제품 밖 상단 도구에 둔다. 실제 규칙·공개·저장은 연결하지 않는다.
