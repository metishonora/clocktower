## 검토를 마치고 유지할 내용

### 광장 대화와 인물 진입

- 하단에는 `광장에 말하기`와 `귓속말` 두 버튼만 둔다. 기록과 말하기를 별도 기능으로 분리하지 않는다.
- 버튼이 위로 확장되어 연결된 대화창이 된다. 광장은 크림색, 귓속말은 청록색으로 구분한다. 다른 채널의 버튼도 남겨 전환할 수 있게 한다.
- 광장 말풍선은 발언자 이름과 사람별 색, 연한 배경으로 구분한다. 채널별 작성 중인 내용을 유지한다.
- 인물을 누르면 `발언 모아보기`와 `귓속말 걸기`를 제공한다. 광장 대화의 발언자 이름으로도 발언을 모아볼 수 있다.
- 발언을 모아보는 중에도 전송 대상은 광장 전체다. 전송하면 전체 대화로 돌아온다.
- 내 직업은 상단에서 제거하고, 광장에서 나를 눌렀을 때 이름 옆 한 줄에 직업 아이콘과 이름을 표시한다. 상단 오른쪽은 공지 아이콘 자리다.

### 입력과 모바일 키보드

- 대화창은 광장 위에 떠 있는 형태다. 열거나 채널을 바꿀 때 키보드를 자동으로 열지 않는다. 입력칸을 직접 눌러 작성한다.
- 대화창은 상단 정보 바로 아래부터 하단 버튼까지 넓게 사용한다. 키보드가 나오면 그 위의 공간을 사용하고, 광장 배경은 이동하거나 재배치하지 않는다.
- Enter로 전송하고 Shift+Enter로 줄바꿈한다. 한글 조합을 확정하는 Enter로 메시지가 전송되지 않게 한다.
- 광장과 귓속말 모두 메시지당 100자 제한과 `0 / 100` 카운터를 전송 버튼 옆에 둔다. 현재 시안은 공백과 줄바꿈을 포함하며, 지원되는 브라우저에서 사용자에게 보이는 문자 단위로 센다.
- 광장 메시지 전송 후 3초 쿨타임을 표시한다. 그동안 다음 문장은 작성할 수 있다. 귓속말에는 쿨타임이 없다.
- 보내기를 눌러도 입력 포커스를 유지한다. 닫을 때 대화창과 연결된 하단 버튼을 함께 처리하여 버튼만 화면 중간에 남는 현상을 줄였다.
- 모바일 구현은 `visualViewport`, 고정된 배경 크기, 페이지 스크롤 억제, iOS 입력 포커스 보정을 포함한다. 이를 일반 모달처럼 바꾸면 사용자가 보고한 화면 이동과 닫힘 문제가 다시 생길 수 있다.

### 귓속말 선택과 새 메시지

- 상대 선택은 길쭉한 목록 대신 4열의 작은 정사각 타일로 표시한다. 8인과 15인에서 나를 제외한 상대를 한 화면에 고르는 방향이다.
- 상대별 안 읽은 수는 타일에, 합계는 하단 귓속말 버튼에 표시한다. 해당 대화를 열면 그 상대의 안 읽은 수만 해제한다.
- 새 귓속말은 하단 버튼을 진한 청록색으로 바꾸고, 보낸 사람과 `새 귓속말`을 약 6초간 표시한다. 봉투와 받은 수를 짧게 강조한다. 누르면 그 상대의 대화를 연다.
- 현재 읽는 상대의 메시지는 대화에 바로 표시한다. 다른 상대에게서 도착해도 현재 초안과 입력 포커스를 유지한다. 강조가 끝나도 안 읽은 수는 남는다.

### 공지

- 초기 알림, 별도 확인, 팝업을 중복시키지 않고 상단 오른쪽 확성기로 모은다.
- 새 공지는 상단에 한 줄로 약 6초간 펼쳐졌다가 아이콘으로 축소한다. 새 공지 수는 유지한다.
- 아이콘을 누르면 아이콘과 연결된 공지 이력 창을 연다. 광장과 귓속말과 구별되는 연한 자주색 배경을 사용한다.
- 이력은 최신순이며 열면 새 공지 표시를 해제한다. 연속 공지는 미리보기에는 최신 내용, 이력에는 모두 남긴다. 작성 중 공지가 와도 초안과 배경을 유지한다.

### 남은 시간

- 상단 시간 숫자를 키우고 원형 표시로 남은 비율을 보여 준다.
- 1분 이하에서는 황금색, 마지막 10초에서는 자주색으로 강조하며 전환 시 짧게 두 번 강조한다.
- 시간 연장은 `+1분`을 약 3초 표시하고 비율에 반영한다. 종료하면 `0:00`과 종료 상태를 표시한다.
- 시안에서는 시간이 끝나도 대화를 계속할 수 있다. 실제 토론 종료와 행동 가능 조건은 아직 서버 규칙과 연결하지 않았다.

### 상대 직업 추측

- 상대 인물 정보에서 이름 옆 `직업 추측`으로 직업을 고른다. 상대마다 하나씩 기록하고 변경하거나 지울 수 있다. 사망한 인물도 가능하다.
- 직업은 주민, 외지인, 하수인, 악마 분류에서 선택하며 즉시 반영한다. 현재 시안은 기존 TB 직업 22종과 아이콘을 재사용한다.
- 내 직업은 기존 읽기 전용 표시를 유지한다. 다른 사람의 실제 직업이나 발언에서 추측을 자동으로 채우지 않는다.
- 선택 화면의 `나만 보기`, `접기` 문구와 인물 정보의 직업 옆 `추측` 접미사는 제거했다. 선택 창은 이름 옆 직업 버튼이나 Esc로 닫을 수 있다.
- **광장과 귓속말 말풍선의 상대 이름 옆에도 기입한 직업 아이콘과 이름을 표시한다.** 변경하거나 지우면 기존 메시지의 표시에도 반영한다.
- 이는 본인용 추측 기록이다. 표시가 상대의 실제 직업 확인을 의미하지 않는다. 현재는 메모리 상태라 새로고침, 시안 초기화, 인원 변경 시 지워진다.

## 보류한 광장 배치

사용자는 검토 05를 본 뒤 “이번 시안은 일단 보류”라고 결정했다. A/B 중 하나를 채택하지 않았다. 보류는 삭제를 뜻하지 않으므로 비교 코드는 남기되, 구현 기준으로 사용하지 않는다.

05의 B에만 있는 다음 변경은 **미채택**이다.

- 광장을 세로로 늘리고 타원 둘레의 간격을 고르게 배치하기.
- 앞뒤 인물 크기를 맞추고 이름 크기를 일정하게 유지하기.
- 최근 발언 두 개를 광장 중앙에 모으기.
- 귓속말 중에도 좌석을 이동하지 않고 고정하기.
- 이 배치에 맞춘 마을 배경과 우물 위치 변경.

구현 위치는 `readableSquare.ts`, `readableSquare.css`와 `SpeakingPlaza.tsx`의 `readableSquare` 분기다. 이 분기는 05에서만 켜며, 04의 기본 광장 배치는 유지한다. 앞선 대화에서 채택한 “말하기 시안 B”와 이번에 보류한 “광장 배치 B”는 서로 다른 결정이다.

## 남은 작업

### 현재 대화에서 이어갈 검토

1. 광장 형태와 먼 인물 가독성, 특히 15인 모바일 배치의 방향은 아직 미확정이다. 보류한 05를 자동으로 재개하거나 채택하지 말고, 다음 사용자 지시에 따라 다시 다룬다.
2. 누가 누구와 귓속말 중인지 보여 주는 표시를 없앨지, 남기되 더 잘 보이게 할지 미정이다. 현재 기본 광장의 자리 이동과 `···` 표시는 초기 시안이다. 새 귓속말 **수신 알림**과는 별개 검토다.
3. 공지 아이콘 옆 `?`를 눌러 화면 기능을 간략하게 설명하는 도움말을 추가한다. **다른 부분을 모두 마친 뒤 마지막에 검토한다는 사용자 지시가 있다. 아직 구현하지 않았다.**

### 이슈 전체 완료까지 남은 범위

기존 설계 댓글의 2차 범위도 계속 유효하다. 이번 대화에서 대화창과 몇 가지 부속 기능을 검토했다고 이슈 전체를 완료 처리하지 않는다.

- 장면 목록과 장면별 필요 정보 및 입력 정리. 입장과 좌석 연결, 역할 확인을 먼저 스케치하고, 낮 토론, 지명과 투표, 밤 대기와 행동 요청 및 정보 도착, 처형과 사망 발표, 사망 후 참여, 게임 종료를 연결한다.
- 기존 마도서 위에 이야기꾼의 접속 상태, 제출 대기, 전달 상태 위치를 스케치한다.
- 초기 밤 장면의 원칙인 모두에게 같은 잠든 광장과 해당 참가자에게만 보이는 개인 카드, 처형 발표와 PC 2단 배치는 기존 컨셉 자료를 참고한다. 이번 작업에서 해당 장면을 새로 구현하거나 승인하지 않았다.
- 결정 사항을 #292 데이터와 입력, #285 화면, #286 진행 인지와 연출, #284 이야기꾼 접점의 요구에 반영한다. 이번 기록으로 해당 이슈들이 갱신된 것은 아니다. 새 작업을 별도 이슈로 나누고 #276에 연결하는 일도 남아 있다.
- 연결 끊김과 제출 상태, 서버 권한과 정보 격리, 실제 메시지 전달, 귓속말 초대와 수락 및 가능 조건, 저장과 복원은 후속 설계 및 구현 범위다.
