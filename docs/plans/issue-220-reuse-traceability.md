## 검증 경계

- P2: 실제 설정/새 게임/배치 복귀 UI, custom WASM의 Setup 검증, IndexedDB의 이전/새 슬롯 상태.
- P3/P4: 실제 마도서 대상 선택/정보 편집/공개/후속 처리, occurrence별 canonical과 당시 payload. [#209 승인 근거](../acceptance/issue-209-mixed-first-night.md)의 R0–R11 전체를 계승하고 원래/획득/안내/재준비 분기를 대표 하나로 대체하지 않는다.
- P5: Production URL의 유틸리티/기록/Undo, 실제 JSON 다운로드·업로드·reload, 현재 메모리와 마지막 저장의 구분.
- P1/P6: 실제 공유 표현을 소비하는 공식 SnV/TB/BMR 회귀, custom 격리, build/PWA, viewport·키보드·공개 포커스. 물리 기기 검증과 viewport 검증을 구분한다.
- 상세 검증 공백은 기존 테스트 결과표의 C08/C15/C20/C21/C23/C29/C30/C32/C34/S1-e에서 이어받는다. 이번 문서 작성으로 통과 상태를 추가하지 않는다.

등록 행동 29개는 계획 v2의 5절 연결표로 별도 추적한다. #209의 추가 준비/모의·획득 능력/재통지/출처·저장 왕복 사례는 이 29개와 함께 확인한다. 타입 union에만 존재하는 낮·이후 밤 기능은 범위가 아니다.
