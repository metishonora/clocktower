## 배정 확인

- **G01-C01**: 15명의 실제 배정과 좌석을 검증한 첫날 밤이며 미배정 후보가 능력을 얻지 않는다.

5. 1번 세탁부: 마을주민 정보
   - **G01-C03**: 1번과 7번 중 7번을 근거로 mathematician 정보를 공개한다.
6. 2번 사서: 시작 정보 준비 / 대상: 1번 · 10번, 캐릭터: 집사, 실제 근거: 10번

8. 3번 수사관: 시작 정보 준비 / 대상: 1번 · 12번, 캐릭터: 독살범, 실제 근거: 12번
9. 3번 수사관: 하수인 정보
   - **G01-C05**: 1번과 12번 중 12번을 근거로 poisoner 정보를 공개한다.

   - **G01-C10**: 첩자가 현재 실제 배역과 상태를 포함한 마도서를 공개한다.
