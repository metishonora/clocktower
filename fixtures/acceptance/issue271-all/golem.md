# 골렘 — 9개 체크포인트

[골렘 검토 서버](http://100.91.205.43:11786/clocktower/)에서 golem/ 파일을 연다. 모두 낮 지명 단계로 시작한다. [공통 절차](README.md)를 함께 적용한다.

기본 9인 명단: 1 서연 골렘 · 2 민준 성자 · 3 지우 시장 · 4 하윤 군인 · 5 도현 독살범 · 6 수빈 임프 · 7 예린 성결자 · 8 시우 처단자 · 9 유나 화가. 은둔자/사랑꾼 파일은 2번 직업만 해당 직업으로 바뀐다.

과학자 10인 명단: 1 P1 화가 · 2 P2 성결자 · 3 P3 시장 · 4 P4 군인 · 5 P5 까마귀지기 · 6 P6 처단자 · 7 P7 장의사 · 8 P8 과학자 · 9 P9 독살범 · 10 P10 임프. 10번이 과학자로부터 골렘 능력을 받았다.

## 조작·기대 결과

| ID · 파일 | 시작 · 조작 | 기대 결과 |
| --- | --- | --- |
| G01 [normal](golem/normal.game.json) | D1 ‘지명하기’ → 1번 골렘 → 2번 성자 → 결과 미리보기 → ‘1번 → 2번 지명 확정’. 별도 분기로 원본을 다시 열어 1→6 임프. | 1→2는 미리보기에 대상·직업·사망. 한 번 확정하면 2번 사망과 골렘 소모를 반영하고 같은 지명의 투표로 바로 이동한다. 사망 확정 모달이 추가로 뜨지 않는다. 생존 8명 기준 필요 표는 4표, 죽은 2번은 유령표를 쓸 수 있다. 성자는 처형 사망이 아니므로 패배하지 않는다. 1→6은 악마여서 사망 없이 능력만 소모되고 투표가 이어진다. |
| G02 [recluse](golem/recluse.game.json) | D1, 1→2 은둔자 지명. (a) 기본 취급, 다시 불러와 (b) ‘악마로 취급’. | 기본은 사망, 악마 취급은 사망 없음으로 미리보기가 바뀐다. 각각 확정한 결과가 미리보기와 같고 두 경우 모두 골렘 사용이 소모된다. 취급이 저장·Undo에 보존된다. |
| G03 [poisoned](golem/poisoned.game.json) | D1, 1번 골렘 중독. 1→2 성자 지명 후 확정. | 진행자에게 중독·사망 없음이 보인다. 대상은 생존해도 지명 사용은 소모된다. 중독이 골렘 자신의 사용 후 지명 제한을 풀어 주지 않는다. |
| G04 [sweetheart](golem/sweetheart.game.json) | D1, 1→2 사랑꾼 지명 확정 → 사랑꾼 사망 후 취할 대상 3번 시장 선택·확정. | 골렘 사망은 즉시 처리되고 사랑꾼의 취함 선택 후 원래 지명의 투표로 이어진다. 골렘 사망 확인을 따로 요구하지 않는다. 투표 확정 전 Undo하면 지명·사망·취함·골렘 소모가 같은 원인 묶음으로 복원된다. |
| G05 [spent](golem/spent.game.json) | D1, 1번은 이미 6번 악마를 지명해 사용을 소모했다. 지명하기에서 1번을 지명자로 골라 보고, 이어 3→1을 선택한다. | 1번은 지명자로 고를 수 없고 ‘지명 불가’로 표시된다. 다른 사람의 지명 대상이 되는 것은 가능하다. |
| G06 [dead](golem/dead.game.json) | D2, 2번 성자는 이미 사망했고 1번 골렘은 미사용. 1→2 지명한다. | 추가 사망 없이 지명·투표가 진행되고 골렘 사용은 소모된다. 기존 사망과 유령표 상태를 유지한다. |
| G07 [boffin-spent](golem/boffin-spent.game.json) | D1, 과학자로 골렘을 얻은 10번 임프가 1번을 지명해 이미 죽인 상태. | 실제 직업은 임프다. 골렘 사용 토큰이 활성 상태이며 10번은 지명자로 고를 수 없다. 10번 본인이 중독되어 있어도 이 제한은 유지된다. |
| G08 [boffin-suspended](golem/boffin-suspended.game.json) | D2, 8번 과학자 중독으로 부여 능력이 중단된 상태. 10→2 성결자를 지명한다. | 골렘 사용 토큰이 X로 비활성 표시된다. 10번은 일반 지명 가능하며 골렘으로 2번을 죽이지 않는다. 기존 골렘 사용 기록을 삭제하지 않는다. |
| G09 [boffin-recovered](golem/boffin-recovered.game.json) | D3, 8번 과학자는 회복했고 이번 중독 대상은 10번 임프다. 지명자 선택과 토큰을 확인한다. | 이전 골렘 사용을 근거로 토큰이 다시 활성화되고 10번의 지명이 다시 제한된다. 10번의 현재 중독이 이 제한을 해제하지 않는다. |

## 결과·복원 인수

- [ ] 사망 예상과 사망 없음 이유를 확정 전에 읽을 수 있고, 확정 결과가 미리보기와 같다.
- [ ] 골렘 사망은 지명 한 번에 처리되고 불필요한 공개 화면·사망 확인이 끼어들지 않는다.
- [ ] 지명 후 저장·새로고침·JSON 재불러오기를 해도 같은 투표, 생사, 사용·유령표 상태다.
- [ ] 지명 직후 Undo하면 사망·골렘 사용·투표 상태가 함께 되돌아간다. 이미 투표를 확정했다면 투표부터 되돌린다.
- [ ] G04의 사랑꾼 후속 효과도 같은 지명 원인과 연결된다.
- [ ] G07–G09의 토큰 활성 상태, 실제 지명 허용 여부, 능력 출처가 서로 일치한다.
