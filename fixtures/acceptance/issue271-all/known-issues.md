# 알려진 실패 — 달의 자손 밤 중독 확정

상태: **미해결, 인수 실패**. 2026-10-09에 현재 BMR 구현의 공개 WASM API와 실제 화면에서 사용하는 컨트롤러 경로로 각각 재현했다. 이번 자료 준비에서는 구현을 수정하지 않았다.

## B20 재현

서버: [BMR 검토 서버](http://100.91.205.43:10271/clocktower/)

파일: [moonchild-night-poisoned.game.json](bmr/moonchild-night-poisoned.game.json)

명단: 1 화가 · 2 군인 · 3 어릿광대 · 4 처단자 · 5 시장 · 6 달의 자손 · 7 은둔자 · 8 독살범 · 9 임프.

파일에 이미 저장된 진행:

1. N2에 임프가 6번 달의 자손을 죽인다.
2. D2 사망 발표 후 달의 자손이 살아 있는 선한 1번 화가를 공개 선택한다.
3. N3에 독살범이 죽은 6번 달의 자손을 중독시킨다.
4. 임프는 정상 군인 2번을 공격하여 죽이지 못한다.
5. 현재 차례는 달의 자손의 예약 사망 확정이다.

사용자 조작:

1. 파일을 불러와 **마도서 이어 쓰기**를 선택한다.
2. 직전 임프 결과가 뜨면 **진행으로 →**로 닫는다.
3. 달의 자손 차례에서 확정 버튼을 누른다.

## 기대와 실제

| 구분 | 결과 |
| --- | --- |
| 기대 | 공개 선택은 유지하되 현재 중독으로 효과가 없어 1번은 생존한다. 그 결과를 확정하고 다음 밤 순서로 이동한다. |
| 현재 | ‘첫날 밤 행동 출처가 올바르지 않습니다.’ 오류가 표시되고 확정하지 못한다. |
| 오류 코드 | INVALID_FIRST_NIGHT_ACTION_PROVENANCE |
| 저장 상태 | 새 확정 이벤트가 추가되지 않고 같은 달의 자손 차례에 머문다. 1번은 생존 상태다. |
| 파일 유효성 | GameFile 파싱, Core 재생, 실제 앱 불러오기, 저장 후 복원은 모두 성공한다. |

이 사례를 PASS로 기록하지 않는다. 공개 WASM에서 confirmStep(input: null)이 거절되고, 화면의 확정 버튼이 호출하는 prepareCurrent()에서도 같은 오류가 난다. 입력 누락이나 손으로 조작한 무효 파일 때문에 생긴 실패는 아니다. 원인은 아직 확정하지 않았다.
