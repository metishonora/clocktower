# 제보 게임 회귀 재현본

`reported-game.json`은 2026-09-25에 제공된 13인 게임의 92개 이벤트를 담는다.
참가자 이름, 게임/시나리오 이름·ID, 자유 형식 이벤트 요약을 익명화했다.
판정에 사용되는 배역, 입력, 결과, 이벤트 ID와 순서는 원본 그대로다.

이 파일은 모든 판정을 새로 정답으로 승인하는 골든 파일이 아니다. 회귀 테스트가
각 저장 시점을 엄격 재생하고, 별도로 확인한 중독·사망·정보 결과를 명시적으로 검사한다.
임의 사망 직전으로 돌아가 보르톡스를 직접 선택하는 컨트롤러·브라우저 경로도 검사한다.

자세한 조사 결과는 [점검 보고서](../../../docs/testing/vortox-pit-hag-audit.md)를 참고한다.
