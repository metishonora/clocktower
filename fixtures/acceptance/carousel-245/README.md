# #245 · 캐러셀 6직업 사용자 인수

개발 이슈 [#237](https://github.com/metishonora/clocktower/issues/237)의 새 직업을 직접 확인하는 자료다. [#232](https://github.com/metishonora/clocktower/issues/232)에서 이미 확인한 기존 직업·일반 투표·처형·저장·PDF 기능은 다시 인수하지 않는다. 기존 직업과 조작은 새 능력의 상호작용을 만드는 데 필요한 경우에만 등장한다.

**검토 앱: [마도서 열기](http://100.91.205.43:10237/clocktower/)** — Tailscale 연결 필요. 최신 #237 프로덕션 빌드이며 프로토타입이 아니다. 검토가 진행되는 동안 서버를 유지한다.

1. `issue245.zip`을 내려받아 압축을 푼다.
2. 앱에서 **Custom Scenario 선택 → JSON에서 불러온다**를 누른다.
3. 먼저 `C01/C01-start.game.json`을 선택하고 **마도서 이어 쓰기**를 누른다.
4. 아래 안내의 사례별 조작·기대 결과를 확인한다. 빠르게 확인하려면 각 사례에 적힌 중간 파일부터 시작해도 된다. 이미 앱 진행 중이면 **저장 / 불러오기**에서 게임 JSON을 불러온다.
5. `results.csv`에 통과/실패/미확인을 적거나 사례 ID와 결과를 #245에 댓글로 남긴다. 실패하면 사용 파일·직전 조작·화면을 함께 남긴다.

## 확인 순서와 범위

- 각 항목은 `시작 파일 → 조작 → 기대 결과` 순서다. 다음 항목에 새 파일이 있으면 현재 게임을 계속 진행하지 말고 그 파일을 불러온다.
- 시나리오 JSON은 후보 풀/순서를 포함한 **배정 전 파일**이다. 게임 JSON은 해당 시나리오까지 포함한 **실제 진행 저장본**이다. 준비 드롭다운은 안내에서 지정한 시나리오 파일로만 따로 확인한다.
- 가장 직업, 과학자의 추가 능력, 픽시의 획득 능력을 실제 직업과 구분한다. 후보 풀에 있다는 이유만으로 사용 완료로 세지 않는다.
- 저장·Undo 확인은 새 과학자/꼭두각시 통지·능력 출처에 연결된 지점만 포함한다. 일반 저장·유령표·기존 승패·기존 47직업·기존 PDF 레이아웃·오프라인 기능의 재검사는 제외한다.
- 새로운 자동화 테스트 코드는 추가하지 않았다. JSON을 실제 Production Core 명령으로 만들고 재생 가능한지 확인했으며, 임시 생성 도구는 이 자료와 저장소에 포함하지 않는다.
- 파일 생성 시 상태 확인, 브라우저의 기본 불러오기 확인, 사용자 직접 인수, 실기기 인수는 서로 다르다. 사용자 및 실기기 결과는 모두 **미확인**으로 시작한다.

## 이미 알려진 상태와 미포함 범위

- **꼭두각시 랜덤 배치:** 현재 임의 배치가 악마 이웃을 자동 보정하지 않을 수 있다. 최종 확정에서 비이웃 배정을 거부하므로 직접 옮겨야 한다. C03-01에서 이 상태를 기록하며 정상 자동 이웃 배치가 된 것으로 세지 않는다. 제품 변경 여부는 개발 #237에서 다룬다.
- 과학자가 부여할 수 있는 모든 능력, 복수 악마·모든 계승 방식, 모든 등록·거짓 정보 조합을 전수 인수한 자료가 아니다. 이번 파일은 새 직업의 대표 정상·실패·경계 장면에 집중한다.
- 광신자의 자동 선택/잠금과 픽시의 즉시 획득은 이번 앱에서 합의한 동작을 확인한다. #237 본문의 오래된 '안내만'·'획득 재확인' 문구를 기대값으로 사용하지 않는다.
- 인수 자료 게시가 사용자 승인이나 개발 이슈 완료를 뜻하지 않는다. 이슈는 열린 상태로 유지한다.
