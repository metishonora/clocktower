# C03 위조된 마을 — 꼭두각시·픽시와 직접 연관된 규칙

개발 #237의 새 직업만 직접 인수한다. #232에서 확인한 저장 기능·일반 투표·기존 직업 자체는 다시 평가하지 않는다. 아래 처형·직업 변경 등은 새 직업의 발동 조건을 만들기 위한 조작이다. 게임 종료까지 진행할 필요는 없다.

이 자료의 파일은 **프로덕션 WASM으로 명령을 실행하고 재생해 생성·검증**했다. 화면·사용자 인수 결과는 전부 **미확인**이다. 모든 캐릭터 조합의 전수 검증을 뜻하지 않는다. 자동 테스트 코드는 추가하지 않았다.

`.game.json`은 게임 불러오기로 열어 **마도서 이어 쓰기**, `.scenario.json`은 시나리오 가져오기로 연다. 중간 파일을 열었을 때 직전 행동의 결과 화면이 먼저 보이면 공개 화면을 닫고 진행한다. 새로 만든 꼭두각시의 비밀 통지는 아래 순서대로 확인하며, 서로 다른 사람에게 보여줄 화면을 한 번에 열지 않는다.

### C03-01. 꼭두각시–열기구 조종사 준비 보정

저장 게임은 이미 배치가 끝난 상태다. **이 항목만** `C03-A.scenario.json`을 가져와 새 마도서를 만들고 준비 화면에서 확인한다.

1. 10명, 위 실제 직업을 선택한다. 실제 열기구 조종사는 넣지 않는다.
2. 직업 확정 위의 **꼭두각시 · 보여줄 직업**이 `선택 필요`에서 시작하는지 보고 **열기구 조종사**를 선택한다. 별도 확정 버튼 없이 반영되어야 한다.
3. 외지인 보정 **+0**에서 주민 7·외지인 0·하수인 2·악마 1인지 확인한다. **+1**로 바꾸면 주민 6·외지인 1이어야 하며 기존 직업 선택은 유지되어야 한다. 현자를 빼고 성자를 추가해 수를 맞춘다.
4. 9번 꼭두각시와 10번 악마를 이웃에 놓아 시작한다. `C03-A1-start.game.json`은 이 +1 배정의 완성본이다.
5. 직업 화면과 시나리오 PDF에서 새 **꼭두각시–열기구 조종사**, **꼭두각시–수학자** 징크스가 한국어로 보이는지 확인한다. 실제 열기구 조종사를 배정하지 않아도 후보 풀 기준으로 표시되어야 한다. 기존 PDF 동작 전반은 재인수하지 않는다.

이 항목은 실제 조종사 없이 **가장 직업만으로 징크스 보정이 적용**되는지 확인한다. 랜덤 배치는 현재 꼭두각시 이웃을 자동 보정하지 않을 수 있다. 비이웃이면 최종 확정에서 거부되는지 확인하고 직접 이웃으로 옮긴다. 자동 이웃 배치가 된 것으로 기록하지 않는다.

### C03-02. 악팀 정보 비대칭

시작: `C03-A-start.game.json` — 첫날 밤 하수인 정보.

1. 하수인 정보를 열어 악마 10번과 통상 하수인 8번을 확인한다. 꼭두각시 9번은 다른 하수인 명단·정보 수신 대상에 포함되면 안 된다.
2. 악마의 속임수는 **야경꾼·화가·성자**를 선택한다.
3. 악마 정보에서 8번 마귀할멈과 별도로 **9번 꼭두각시**가 알려지는지 확인한다. 꼭두각시를 깨워 악팀 정보를 주라는 진행은 없어야 한다.

### C03-03. 픽시의 보르톡스 정보

시작: `C03-A-pixie-info.game.json` — 첫날 밤 1번 픽시.

1. 집착 대상 **2번 백치천재**를 선택한다.
2. `알려줄 직업`에서 **야경꾼**을 선택한다. 현재 배정된 백치천재·수학자·군인 등은 없어야 하고, 시나리오에 있지만 배정하지 않은 주민만 허용되어야 한다.
3. 공개 화면에는 **야경꾼 직업만** 보여야 한다. 2번의 번호·이름·실제 직업을 같이 보여주면 실패다.
4. 이야기꾼 마도서에는 2번을 발동 대상으로 연결한 픽시의 **집착** 토큰이 있어야 한다.

### C03-04. 꼭두각시는 보르톡스 거짓 강제 대상이 아님

시작: `C03-A-balloonist.game.json` — 첫날 밤 9번의 가장 열기구 조종사. 첫밤은 표시 형태를 보고, 아래 **둘째 밤 분기에서 보르톡스 면제를 판단**한다.

1. 기존 주정뱅이와 같은 가장 정보 구조, **주황색 꼭두각시** 상태, 보여준 직업 **열기구 조종사**를 확인한다.
2. **1번 픽시**를 알려줄 사람으로 선택·공개한다. 첫밤에는 이전 유형이 없으므로 이것만으로 보르톡스 면제를 통과 처리하지 않는다.
3. 다음 수학자 화면의 진실은 **1**이다. 이 1은 픽시가 보르톡스로 틀린 직업을 받은 결과이며, 가장 열기구의 첫 정보 자체를 무조건 오작동으로 더한 2가 아니다. 보르톡스 때문에 수학자에게는 **0**을 전달하고 낮으로 간다.
4. **별도로 `C03-A-balloonist-night2.game.json`을 연다.** 둘째 밤 9번의 가장 열기구 입력 직전이며 지난밤 알려준 1번은 **주민**이다. 이번에는 **8번 마귀할멈(하수인)**을 골라 공개한다. 지난밤과 다른 유형인 **참 정보**인데도 보르톡스가 있다는 이유로 거부하거나 다른 유형 전달을 막으면 실패다. 이 분기는 여기서 멈춘다.

이 둘째 밤 8번 선택은 프로덕션 WASM 명령·재생으로 적법함을 확인했다. C03-06까지 직접 이어가는 원래 경로는 아래처럼 **3번**을 선택하므로 서로 섞지 않는다.

### C03-05. 알려준 능력의 즉시 획득

시작: `C03-A-pixie-death.game.json` — 첫날 낮, 아직 집착 판정 전.

1. 픽시 자유행동에서 **1번이 야경꾼에 충분히 집착했는가**를 **충분히 집착함**으로 정한다.
2. 사망 발표·토론을 지나 지명으로 이동한다. **1번이 2번 지명**, **1~6번 찬성**으로 확정하고 지명 종료 → 처형 확인 → 사망 확인한다.
3. 별도 획득 질문이나 플레이어 공개 없이 픽시가 **야경꾼 능력**을 즉시 얻어야 한다. 실제 사망자의 백치천재 능력을 얻으면 실패다.
4. 2번의 픽시 토큰은 **능력 가짐**, 1번에는 획득한 능력 표시가 생기고, 픽시 집착 자유행동은 사라져야 한다. 결과 비교용은 `C03-A-acquired.game.json`이다.

### C03-06. 획득한 야경꾼은 실제로 작동함

바로 시작: `C03-A-acquired-nightwatchman.game.json` — 둘째 밤, 1번 픽시가 얻은 야경꾼 진행.

1. 통지 대상 **4번 군인**을 선택한다.
2. 보르톡스가 있으므로 `야경꾼으로 알려줄 사람`은 실제 능력 소유자인 1번 대신 **3번 수학자**를 선택한다.
3. 4번에게만 3번이 야경꾼이라는 신원 통지가 나와야 하며, 사용 후 **능력 사용함** 상태가 되어야 한다. 꼭두각시의 가짜 야경꾼처럼 통지 자체가 없어지면 실패다.

직접 이어 왔다면 둘째 밤에 마귀할멈은 **3번→수학자**(이미 있는 직업이므로 변경 없음), 보르톡스는 **6번 공격**, 가장 열기구 조종사는 **3번**을 알려준 뒤 이 단계에 도달한다. **C03-04의 8번 전달은 별도 파일에서 확인하는 분기**다. 첫밤 1번과 둘째밤 3번은 둘 다 주민이지만 꼭두각시의 거짓 정보로 허용된다. 이 항목에서는 추가 수학자 숫자를 맞히는 것을 별도 인수로 요구하지 않는다.

## B. 게임 중 꼭두각시 생성 — 5인

배정: 1 백치천재 / 2 화가 / 3 군인 / 4 마귀할멈 / 5 임프. 시작: `C03-B-create-marionette.game.json` — 둘째 밤 마귀할멈.

### C03-07. 본인과 악마에게 이어서 통지

1. 마귀할멈이 **2번→꼭두각시**를 선택한다. 변경 결과 화면을 닫아 다음 진행으로 간다.
2. 꼭두각시 아이콘·이름·능력 설명이 있는 기존 진행 UI에서 `보여줄 직업`이 **선택 필요**로 시작하는지 확인한다. **야경꾼**을 선택하고 확정한다. 준비 화면을 다시 띄우거나 장문의 별도 안내 페이지를 요구하면 실패다.
3. **2번에게만 선·야경꾼**으로 변경됐음을 공개하고 닫는다. 실제 직업은 꼭두각시이며, 마귀할멈은 진영을 바꾸지 않으므로 실제 진영도 선이다.
4. 이어 **5번 악마에게만 2번이 꼭두각시**라는 정보를 공개한다. 2번 화면에 이 정보가 섞이면 실패다.
5. 마도서에서 실제/보여준 직업 분리를 확인한다. 2번은 악마의 이웃이 아니지만 **중도 생성이므로 최초 배치 이웃 조건을 다시 적용해 거부하면 실패**다.

`C03-B-choose-shown.game.json`은 2번 직업 선택 직전, `C03-B-private-reveals.game.json`은 선택 확정 후 두 비밀 통지가 남아 있는 비교용이다. 이 사례는 새로운 악마의 생성이나 꼭두각시의 악 진영 전환을 시험하는 사례가 아니다.

## C. 꼭두각시–수학자 징크스 — 5인

배정: 1 수학자 / 2 백치천재 / 3 화가 / 4 꼭두각시(야경꾼) / 5 임프. 보르톡스가 없어 숫자를 직접 비교할 수 있다.

시작: `C03-C-fake-nightwatchman.game.json` — 첫날 밤 4번의 가장 야경꾼. 같은 파일을 두 번 열어 독립적으로 비교한다.

| 사례 | 조작 | 기대 |
| --- | --- | --- |
| C03-08 사용 | 대상 **2번**을 선택해 사용 | 실제 신원 통지가 없어야 한다. 다음 1번 수학자의 진실·공개 숫자는 **1**. 가짜 능력의 효과 불발을 센다. |
| C03-09 미사용 | **오늘 사용하지 않음** | 별도 확인 문구 없이 진행하고 미사용 유지. 다음 수학자의 숫자는 **0**. 가짜 직업을 가지고 있다는 이유만으로 세지 않는다. |

결과 비교용: `C03-C-math-one.game.json`, `C03-C-math-zero.game.json`. 두 파일 모두 첫날 밤 수학자 단계다. 여기서 확인하는 징크스 근거는 **효과 불발과 미사용**의 차이다. 모든 가장 정보직의 참·거짓 조합을 검증했다고 기록하지 않는다.

## D. 픽시 첫 정보의 중독 — 5인

배정: 1 픽시 / 2 백치천재 / 3 화가 / 4 독살범 / 5 임프. **보르톡스 없음**. 독살범이 이미 1번을 중독시켰다.

### C03-10. 배정된 주민 / 미배정 주민 둘 다 허용

시작: `C03-D-poisoned-pixie.game.json` — 첫날 밤 1번 픽시.

1. 집착 대상은 **2번 백치천재**를 선택한다. `알려줄 직업`에 게임에 있는 **화가**와 없는 **야경꾼**이 모두 있는지 확인한다.
2. **화가**를 선택해 공개한다. 화면에는 화가만 있고 대상 2번은 없어야 한다. 확인 후 멈춘다.
3. 같은 시작 파일을 다시 열어 2번을 선택하고 이번에는 **야경꾼**을 공개한다. 이것도 허용되어야 한다.

`C03-D-told-inplay.game.json` / `C03-D-told-absent.game.json`은 각 정보 확정 후 낮 시작 직전 비교용이다. 중독 상태에서 대상이 죽는 분기는 C02에서 따로 다루며 여기서 반복하지 않는다. 보르톡스와 중독이 동시에 있는 모든 조합은 이 C03 묶음의 직접 인수 범위가 아니다.
