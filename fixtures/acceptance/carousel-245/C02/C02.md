# C02 남겨진 집착 — 픽시·실제 야경꾼

이번에 추가한 **픽시·야경꾼과 그 직접 상호작용만** 확인한다. #232에서 인수한 투표·처형·낮밤 전환·독살범·마귀할멈 자체를 다시 평가하지 않는다. 이들은 아래 장면을 만드는 조작으로만 사용한다.

생성 시 Production WASM의 실제 명령·재생으로 배정 분포와 13개 기대 상태를 확인했다. **사용자 화면·실기기 인수는 아직 미확인**이다. 별도 테스트 코드 실행은 필요 없다.

## 준비

가장 빠른 방법은 아래 각 사례의 `.game.json`을 게임 파일로 불러와 **마도서 이어 쓰기**를 선택하는 것이다. `.scenario.json`은 후보 풀·순서를 새로 등록할 때만 사용한다. 파일 불러오기 시 직전에 확정했던 결과 화면이 먼저 보이면 그 결과를 닫고 다음 진행으로 이동한다.

전체 진행을 원하면 `C02-00-start.game.json`에서 시작한다. 10인 분포는 주민 7·외지인 0·하수인 2·악마 1이다. 좌석은 재현용으로 고정했으며 별도 좌석 규칙을 시험하는 게임은 아니다.

| 좌석·이름 | 실제 배정 | 이 게임에서의 용도 |
| --- | --- | --- |
| 1 민지 | 픽시 | 새 직업 인수 대상 |
| 2 태오 | 야경꾼 | 픽시의 집착 대상·새 직업 인수 대상 |
| 3 지온 | 군인 | 일반 경로에서 중독을 받는 보조 대상 |
| 4 하린 | 백치천재 | 일반 경로의 밤 사망 대상 |
| 5 도윤 | 화가 | 야경꾼 통지 수신자 |
| 6 서윤 | 재봉사 | 능력은 보류한다 |
| 7 은호 | 철학자 | 능력은 보류한다 |
| 8 수아 | 독살범 | 픽시·야경꾼 중독 분기를 만든다 |
| 9 시우 | 마귀할멈 | 집착 대상의 직업 변경 분기를 만든다 |
| 10 유나 | 임프 | 집착 대상의 밤 사망을 만든다 |

미배정 후보·악마 속임수는 **요리사·시장·성자**다. 요리사는 대상 직업 변경 분기에서만 새로 들어온다.

처음부터 진행하는 경우: 철학자 보류 → 하수인 정보 → 위 세 속임수로 악마 정보 → 독살범은 3번 → 픽시는 2번을 대상으로 야경꾼을 알려줌 → 재봉사 보류 → 야경꾼 보류 → 낮 시작. 이후 아래 분기별 파일로 돌아가 비교한다.

## A. 픽시 첫 정보와 집착 자유행동

### C02-P01 — 첫 정보에 대상이 노출되지 않는가

시작: **[C02-01-pixie-information.game.json](C02-01-pixie-information.game.json)**

1. 픽시의 대상 선택에서 **2번 태오**를 선택한다.
2. 이야기꾼 화면의 집착 대상은 2번이고 알려줄 직업은 **야경꾼**인지 확인한다.
3. 픽시에게 공개한다. 공개 화면에는 **야경꾼 아이콘·직업**만 나오며 **2번/태오가 노출되지 않아야 한다**.
4. 공개를 닫고 마도서에서 **2번에 픽시 아이콘의 `집착` 토큰**이 있는지 확인한다.

- [ ] C02-P01 통과

### C02-P02 — 충분히 집착한 상태에서 대상 사망

시작: **[C02-03-pixie-judgment.game.json](C02-03-pixie-judgment.game.json)** — 1일차 낮, 2번 생존, 1번 픽시 정상 상태.

1. 픽시의 **집착 확인 자유행동**을 연다. 1번 민지가 야경꾼에 충분히 집착했는지 묻고, **`충분히 집착함` / `집착하지 않음`** 두 판단이 보여야 한다.
2. `집착하지 않음`을 한 번 선택했다가 다시 열어 `충분히 집착함`으로 바꾼다. 마지막 판단이 유지되어야 한다.
3. 지명/투표까지 진행해 **3번이 2번을 지명**, **1·3·4·5·6·7번의 6표**를 확정한다. 지명 종료 → 처형 확정 → 사망 확인을 진행한다.
4. **사망 순간 즉시** 1번이 야경꾼 능력을 얻어야 한다. 실제 직업은 픽시를 유지한다.
5. 2번의 픽시 토큰은 **`능력 가짐`**으로 바뀌고, 픽시 집착 자유행동은 사라져야 한다. “능력을 얻을까요?” 같은 후속 질문이나 획득 사실 공개를 다시 요구하면 실패다.

결과 참고: [C02-04-acquired-day.game.json](C02-04-acquired-day.game.json)

### C02-P03 — 얻은 능력이 실제 작동하는가

바로 시작: **[C02-05-acquired-nightwatchman.game.json](C02-05-acquired-nightwatchman.game.json)** — 2일차 밤, 2번은 사망했고 1번이 얻은 야경꾼 단계.

1. 진행 주체가 **1번 민지**인 야경꾼 능력인지 확인한다. 2번의 단계여서는 안 된다.
2. 통지 대상으로 **5번 도윤**을 선택해 사용한다.
3. 5번에게 공개하는 정보가 **1번 민지가 야경꾼 능력 사용자**임을 알리는지 확인한다. 죽은 원래 야경꾼 2번을 알려주면 실패다.
4. 닫으면 1번이 얻은 야경꾼 능력에 사용 기록/토큰이 남아야 한다. 실제 직업은 계속 픽시다.

결과 참고: [C02-06-acquired-used.game.json](C02-06-acquired-used.game.json)

## B. 픽시의 획득 실패·직업 변경 분기

### C02-P04 — 불충분한 집착이면 흔적을 정리하는가

**C02-03-pixie-judgment.game.json을 다시 불러온다.**

1. 픽시 자유행동에서 **`집착하지 않음`**을 선택한다.
2. A의 C02-P02와 같은 6표로 2번을 처형·사망 확인한다.
3. **야경꾼 능력을 얻지 않아야 한다.** 2번의 `집착` 토큰도 제거되고 픽시 자유행동도 사라져야 한다.

### C02-P05·P06 — 대상 사망 당시 중독, 나중에 회복

시작: **[C02-08-poisoned-target-death.game.json](C02-08-poisoned-target-death.game.json)** — 2일차 밤 임프 단계. 1번은 충분히 집착했지만 지금 독살범에 중독되어 있다.

1. 마도서에서 **1번 중독 / 2번 생존**을 확인한다.
2. 임프로 **2번을 공격**한다.
3. 2번 사망 후 **1번이 야경꾼 능력을 얻지 않고**, 픽시의 `집착` 토큰도 남지 않아야 한다. 여기서 획득 여부를 별도로 묻지 않는다.
4. 회복 확인은 **[C02-09-recovered-no-acquisition.game.json](C02-09-recovered-no-acquisition.game.json)**을 불러온다. 다음 밤 독살범은 3번으로 옮긴 상태다.
5. 1번의 중독이 끝났어도 **야경꾼 능력이 새로 생기지 않고**, 픽시 자유행동도 돌아오지 않는지 확인한다.

### C02-P07 — 대상 직업이 바뀌어도 처음 알려준 능력인가

시작: **[C02-10-target-character-change.game.json](C02-10-target-character-change.game.json)** — 2일차 밤 마귀할멈 단계. 1번은 야경꾼에 충분히 집착했고 정상 상태다.

1. 마귀할멈으로 **2번을 요리사**로 바꾼다. 본인에게 변경 사실을 전달하고, 이어지는 새 요리사 시작 정보는 그대로 전달·확정한다. 이 기존 직업의 정상 동작 자체는 인수 항목이 아니다.
2. 다음 임프 단계에서 **2번을 공격**한다.
3. 재봉사는 보류한다. 1번에게 생긴 능력이 **요리사가 아니라 야경꾼**이어야 한다.
4. 1번의 야경꾼으로 **5번을 선택**하면 5번에게 **1번**을 알려야 한다.

직업 변경·사망을 끝낸 바로 시작점: [C02-11-original-ability-after-change.game.json](C02-11-original-ability-after-change.game.json)

### C02-P08 — 픽시가 먼저 죽은 경우

시작: **[C02-16-pixie-died-first.game.json](C02-16-pixie-died-first.game.json)** — 3일차 밤 임프 단계. 1번 픽시는 전날 밤 사망, 2번 야경꾼은 생존 상태.

## C. 실제 야경꾼의 보류·사용·중독

### C02-N01·N02 — 실제 사용, 단 한 번의 기회

시작: **[C02-02-nightwatchman.game.json](C02-02-nightwatchman.game.json)** — 1일차 밤, 정상인 실제 야경꾼 2번의 단계.

1. **5번 도윤**을 선택해 사용한다.
2. 5번에게만 **2번 태오가 야경꾼**이라는 공개가 나오는지 확인한다. 2번의 `능력 사용함` 토큰을 확인한다.
3. 다음 밤까지 이어서 확인하려면: 낮 시작 → 처형 없이 밤 진행 → 철학자 보류 → 독살범 3번 → 마귀할멈 3번을 군인으로 선택(이미 군인이므로 변화 없음) → 임프 4번 공격 → 재봉사 보류.
4. **살아 있는 2번의 야경꾼 사용 단계가 다시 나오지 않고 낮 시작으로 진행**해야 한다.

사용 직후 참고 파일: [C02-12-native-nightwatchman-used.game.json](C02-12-native-nightwatchman-used.game.json)

### C02-N03 — 보류는 확인창 없이 진행, 기회 유지

**C02-02-nightwatchman.game.json을 다시 불러온다.**

1. **`오늘 사용하지 않음`**을 누르면 별도 확인 문구 없이 다음 단계로 가야 한다.
2. 사용함 토큰은 없어야 한다.
3. C02-N02의 다음 밤 진행과 같은 조작을 한다.
4. 이번에는 **2번의 야경꾼 단계가 다시 있어야 한다**. 사용할 수 있거나 다시 보류할 수 있어야 한다.

### C02-N04·N05 — 중독 중 사용도 소진, 회복해도 복구하지 않음

시작: **[C02-13-poisoned-nightwatchman.game.json](C02-13-poisoned-nightwatchman.game.json)** — 1일차 밤, 독살범이 2번을 중독시켰다.

1. 2번 야경꾼이 **5번을 선택**해 사용한다.
2. **5번에게 보여줄 통지는 없어야 한다.** 그러나 2번은 `능력 사용함` 상태가 되어야 한다.
3. 사용 직후 상태는 [C02-14-poisoned-nightwatchman-used.game.json](C02-14-poisoned-nightwatchman-used.game.json)에서도 확인할 수 있다.
4. 회복 후 확인은 **[C02-15-recovered-nightwatchman-spent.game.json](C02-15-recovered-nightwatchman-spent.game.json)**을 불러온다. 2번은 생존, 중독 대상은 3번으로 옮겨졌다.
5. 이 밤의 다음 단계는 **낮 시작**이다. 중독이 풀려도 2번에게 사용 기회가 돌아오지 않아야 한다.

## 범위와 결과 기록

- `coverage.json`은 위 13개 사례의 생성 시 검증, 시작 파일, 재현 명령을 연결한 자료다. 사용자·실기기 결과는 모두 `unverified`로 두었다.
- 보르톡스·첫 정보 오류 조건의 픽시는 C03에서 확인한다. 이 문서에 중복 인수 항목을 넣지 않았다.
- 결과는 사례 ID와 함께 **통과 / 실패 / 미확인**, 사용 기기·브라우저, 실제 화면 또는 재현 방법을 신규 인수 이슈에 남긴다.
- 파일을 만들기 위해 사용한 임시 생성 스크립트는 인수 배포 자료나 제품 테스트 코드에 포함하지 않는다.
